# Answers

One file per study day: `day1-diagnostic.md`, `day1.md`, `day2.md`, … `day6-mock.md`. Write each answer **before** checking it against `EXAM-NOTES.md`, then mark it:

- ✅ right
- 🟡 partly: what was missing
- ❌ wrong: **why** (misread the code? didn't know the concept? couldn't find the page?)

On Day 7 you re-read only the ❌/🟡 lines. If the reason was "couldn't find the page", improve the index or headings in `EXAM-NOTES.md`. If it was "didn't know the concept", add a line in your own words to the matching notes section.
