# Answers

One file per topic: `day1.md`, `day2.md`, … `day7.md`, then `day8-mock.md` and `day9-dummy.md`. Each one is pre-filled with the headings for that day's Must questions, so you only write the answers. `logistics.md` holds the exam facts you look up in step 0.1.

Write each answer **before** checking it against `EXAM-NOTES.md`, then mark it:

- ✅ right
- 🟡 partly: what was missing
- ❌ wrong: **why** (misread the code? didn't know the concept? couldn't find the page?)

On Day 9 you re-read only the ❌/🟡 lines. If the reason was "couldn't find the page", improve the index or headings in `EXAM-NOTES.md`. If it was "didn't know the concept", add a line in your own words to the matching notes section.
